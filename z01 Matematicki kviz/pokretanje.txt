Struktura:

Shared  - zajednicki ugovor i serijalizovani tipovi koje moraju da imaju i server i klijent
Server  - serverska implementacija i serverska main klasa
Klijent - klijentska main klasa

Server racunar:

cd Server
javac -d . ..\Shared\*.java *.java
java Server

Klijent racunar:

cd Klijent
javac -d . ..\Shared\*.java *.java
java Klijent

Ako server nije na istom racunaru, klijent se pokrece ovako:

java Klijent IP_ADRESA_SERVERA
